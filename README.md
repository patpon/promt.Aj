## วิธีใช้

1. เลือกงานด้านบน
2. กด **🏷️ ข้อมูลงาน** กรอกครั้งเดียว (ชื่อร้าน ระบบที่ใช้ ฯลฯ) — ทุก prompt ในงานนั้นจะใช้ข้อมูลนี้อัตโนมัติ
3. เลือก prompt → กรอกช่อง → ดูตัวอย่างทางขวา
4. กด **คัดลอก** หรือ **ChatGPT / Claude / Gemini** เพื่อเปิดแชทพร้อม prompt
5. กด 🔗 เพื่อคัดลอกลิงก์ prompt นั้นส่งให้เพื่อนร่วมทีม

ค่าที่กรอก, ข้อมูลงาน, prompt ที่ชอบ และ prompt ที่เพิ่มเอง เก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น (ไม่ส่งไปไหน)

## เพิ่ม prompt

**แบบเร็ว (เฉพาะเครื่องตัวเอง):** กด **＋ เพิ่ม prompt** ในเว็บ แล้ว **ส่งออก JSON** ไว้แชร์ให้ทีม **นำเข้า JSON** ได้

**แบบถาวร (ทุกคนเห็น):** แก้ไฟล์ [`prompts.js`](prompts.js) เพิ่ม object ใน `PROMPTS`

```js
{
  id: "gb-xxx",            // ไม่ซ้ำกัน
  biz: "goldbread",        // goldbread | rabiangbua | wandeedee | shopee
  cat: "IT Support",       // หมวด
  title: "ชื่อ prompt",
  desc: "คำอธิบายสั้น",
  prompt: `คุณคือ ...

{{@profile}}

งาน: {{รายละเอียด}}`
}
```

### รูปแบบช่องกรอก

| เขียนแบบนี้ | ได้ |
|---|---|
| `{{ชื่อช่อง}}` | ช่องกรอก (ต้องกรอก) |
| `{{ชื่อช่อง:ค่าเริ่มต้น}}` | ช่องกรอกพร้อมค่าเริ่มต้น |
| `{{ชื่อช่อง:}}` | ช่องไม่บังคับ (เว้นว่าง = `-`) |
| `{{ชื่อช่อง:ก\|ข\|ค}}` | dropdown ตัวเลือก |
| `{{@profile}}` | แทรกข้อมูลงานทั้งหมด |

ชื่อช่องที่ตรงกับหัวข้อใน "ข้อมูลงาน" จะเติมให้อัตโนมัติ

เพิ่มงาน/ธุรกิจใหม่: เพิ่ม object ใน `BUSINESSES` (id, name, emoji, tagline, color, profile)
